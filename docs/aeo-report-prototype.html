High+5 pts organization.jsonld

Organization schema identifies the company

No Organization JSON-LD anywhere we looked. This is the block that tells an engine you're one entity across your site and your social profiles.

Organization JSON-LD — paste into <head> 
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Linkup",
  "url": "https://www.linkup.so/",
  "logo": "{{LOGO_URL}}",
  "description": "The production-grade Web Search API for AI. Used by McKinsey, SNCF, Cohere, Legora, Polymarket.",
  "sameAs": [
    "https://www.linkedin.com/company/linkup-platform",
    "https://x.com/Linkup_platform"
  ]
}
</script>

Put it at <head> on https://www.linkup.so/. The 2 sameAs links were read off your live site — nothing invented.

⚠ Heads up. {{LOGO_URL}} is a placeholder — no og:image on your homepage, so we have no logo URL to cite.

Ahead of curve+2 pts robots.txt

Content Signals state usage permissions

No Content Signals in robots.txt. These state whether your content may be indexed, used to ground an answer, or used for training.

Content Signals — add to robots.txt 
# Content Signals: state how your content may be used.
#   search   = appearing in a search index
#   ai-input = used as grounding for a generated answer (RAG)
#   ai-train = used to train or fine-tune a model
User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no
Allow: /

Put it at https://www.linkup.so/robots.txt. Shown with the common stance: be findable and quotable, but don't be training data. Change any value to match what you actually want.
